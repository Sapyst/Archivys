# Archivys

**Alpha v0.1** — an idle guild-management game for mobile (portrait), made with Godot 4.

Run a crumbling branch of the *Archive of Illamar* in the world of **Kaavuh'kaat**: open the doors, serve
adventurers during the Breakfast, Lunch and Supper rushes, cook for the next day, hire staff, take contracts
from the realm and grow your guild from a dusty hole into a grand hall.

## Play
- **Android:** download `Archivys-v0.1-alpha.apk` from the [Releases](../../releases) page and install it
  (allow "install from unknown sources").
- **From source:** open `godot/` with Godot 4.7 and press Play.

## Core loop
- **Rushes:** orders fall onto the tables — drag the right dish from the tray before they arrive (combo = tips).
- **Kitchen:** trace the cooking strokes in 5 seconds (1 stroke for simple food, 5 for a banquet).
- **Guild:** buy ingredients, hire a Receptionist, Cook and Server, build upgrades, send parties on contracts
  into the Mau'Vhin valleys. Well-fed, happy adventurers succeed more often.

## Repository
- `godot/` — the game project (UI built in code, mini-games in `scripts/minigames/`).
- `arte/geradores/` — Python generators for the pixel-art UI (rope windows, metal panels, fonts, HUD, icons).
- `docs/` — design decisions, balancing and lore.
